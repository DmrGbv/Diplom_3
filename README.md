# Автоматизация UI-тестирования [Stellar Burgers](https://stellarburgers.education-services.ru/)

## О проекте

В рамках дипломного проекта разработан набор автоматизированных UI-тестов для веб-приложения **Stellar Burgers**.

Проект реализован на Java с использованием Selenium WebDriver и JUnit 4. Для формирования отчетов используется Allure Report.

---

## В рамках проекта

- разработана архитектура UI-тестов;
- реализованы Page Object классы;
- автоматизированы пользовательские сценарии;
- настроено формирование отчетов Allure.

---

## Покрытие тестами

Автоматизированы следующие сценарии:

### Регистрация

- успешная регистрация;
- регистрация с некорректным паролем.

### Авторизация

- вход через главную страницу;
- вход через личный кабинет;
- вход через форму восстановления пароля;
- вход через форму регистрации.

### Конструктор бургеров

- переход между разделами конструктора;
- проверка работы вкладок.
